      Sample / approximate data. This guide is a portfolio project, not a live fare board. Operators in Lusaka change routes and fares. Ask the conductor before you pay.

      Update a route or a fare
      1. Edit data/routes.json. Each stop has an id. Each route lists those ids in travel order and a fareZmw amount.
      2. The search treats a route as running both ways. You do not store the reverse copy.
      3. One-change fares are calculated by adding the two sample fares. You do not store them.
      4. Run node --test tests/search.test.js. It checks that every stop can still reach every other stop within one change.
      5. Refresh the site. If an old page sticks, bump CACHE_NAME in sw.js.

      Keep the sample label. Real fares need a fresh check on the ground.
